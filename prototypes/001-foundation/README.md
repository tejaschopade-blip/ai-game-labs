# 001 — Foundation Prototype

Validates that the core architecture works end-to-end.

**Question being tested:** Does the Phaser + Vite + TypeScript foundation boot correctly?

## What it does
- Boots through BootScene → PreloadScene → PrototypeScene
- Shows debug overlay (FPS, scene name, prototype name)
- Demonstrates InputManager and AudioManager wiring
- R key restarts the scene
