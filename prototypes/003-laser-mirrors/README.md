# Prototype 003 — Laser Mirrors

## Mechanic

Rotate mirrors to redirect a laser beam and hit the target.

## Core interaction

Click/tap a mirror → it toggles between / and \ → laser immediately recalculates.

## Hypothesis

Can a very small indirect-interaction puzzle create satisfying spatial reasoning?

## Controls

- Click/tap a mirror to rotate it
- R to restart the current level

## Levels

1. One mirror — learn the basic deflection
2. Two mirrors — both need rotating, two bends
3. Walls — blocked paths force mirror planning
4. S-shaped path — four mirrors, longer reasoning chain
5. Combined — two mirrors start correct (trap: clicking them breaks the path)

## What we're testing

- Is the mechanic immediately understandable?
- Is laser feedback satisfying?
- Does rotating mirrors feel meaningful?
- Do players naturally plan the full beam path ahead?
- Does difficulty increase naturally across 5 levels?
- Do players want more levels after finishing?

## Deliberately excluded

- Timer, lives, economy
- Procedural generation
- External art assets
- Move counter (added only if mechanic is validated)
- Progression system
