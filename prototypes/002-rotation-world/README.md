# 002 — Rotation World

**Question being tested:** Is rotating the world after each move a fun/interesting mechanic?

## How it works
- Move with WASD or arrow keys
- Every valid step rotates the entire world 90° clockwise
- Input is always screen-fixed (RIGHT always = screen-right) but the world rotation changes what's reachable
- Reach the green ★ to win

## What to evaluate
- Does the rotation feel satisfying?
- Does it create interesting decisions?
- Is it disorienting or readable?
- Would adding gravity to the rotation add more depth?
