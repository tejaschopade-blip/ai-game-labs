# Prototype 005 — Chain Reaction

## Core mechanic

Tap one circle, trigger a cascading chain reaction.

## Core interaction

Tap → expand → activate nearby object → repeat.

## Hypothesis

Can a single satisfying interaction create enough anticipation and feedback to make players want to try again?

## Controls

Mouse / Touch: Tap a circle

## Scenarios

1. Easy — tight cluster, any tap works
2. Medium — moderate spacing, choose wisely
3. Split — two clusters, pick one
4. Precision — one starting point creates a much bigger chain
5. Big — 50 objects, go for the max

## What we're testing

- Is the mechanic immediately understandable?
- Is the expanding ring → neighbor activation visually clear?
- Does the player naturally search for a better starting point?
- Does watching the chain unfold create anticipation?
- Does the player want to retry after a small chain?
- Does a large chain feel meaningfully better?

## Deliberately excluded

Economy, progression, powerups, enemies, multiplayer, procedural generation, timers, lives, complex controls.
