# Prototype 006 — Steal Properties

## Core mechanic

Touch a property source → become that property → interact with the environment differently.

## Properties

- **FIRE** — burn wood blocks (visual feedback, opens sub-routes)
- **ICE** — freeze water (creates passable surface through the divider wall)
- **MAGNET** — attract the metal block toward you (demonstration)

## Hypothesis

Does changing your capability through physical contact create interesting moment-to-moment decisions?

## The key question

After stealing Fire and burning wood, do you immediately wonder "what does Ice do?"

## Controls

WASD / Arrow Keys — move  
Walk into property sources to steal them  
R = restart  
ESC = menu

## Level structure

One room split into Left and Right chambers by a vertical divider wall.

The only passage is a gap in the divider, blocked by water.

Critical path: get ICE → freeze water → walk through → reach goal.

Secondary: get FIRE → burn wood blocks (decorative, shows mechanic).  
Tertiary: get MAGNET → pull metal block (shows mechanic).

## Deliberately excluded

Combat, inventory, UI menus, economy, progression, multiplayer, procedural generation, audio assets, multiple levels.

## Known limitations

- Single level only
- Magnet mechanic is decorative (metal block doesn't gate anything)
- No difficulty curve
- Water position is fixed (same x as divider wall — narrow)
